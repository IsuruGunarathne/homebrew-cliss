# homebrew-cliss

Homebrew tap for [CLISS](https://github.com/IsuruGunarathne/CLISS), animated screensavers for your terminal.

```bash
brew install isurugunarathne/cliss/cliss
cliss
```

Update with `brew upgrade cliss`, remove with `brew uninstall cliss`.

The formula is updated automatically by CLISS's release workflow, so there's nothing to change here by hand.
